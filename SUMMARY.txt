SUPPORTED FIRMWARE FORMATS
--------------------------
• Xiaomi: .dat.br, .dat (MIUI, HyperOS)
• OnePlus: payload.bin (OxygenOS)
• Samsung: .tar.md5, .lz4 (OneUI)
• Oppo/Realme: .ozip (ColorOS, RealmeUI)
• Motorola: sparsechunk
• Google: payload.bin (Pixel)
• ASUS: .img (RogUI)
• Tecno: HiOS (various formats)
• Infinix: XOS (various formats)
• Itel: ItelOS (various formats)
• Dynamic partitions: super.img

QUICK START
-----------
1. Run install.sh to install dependencies:
   chmod +x install.sh && ./install.sh

2. Run the main script:
   python3 gsi_converter_tools.py

3. Follow the interactive menu or use command-line options

USAGE EXAMPLES
--------------
# Interactive mode
python3 gsi_converter_tools.py

# Extract firmware
python3 gsi_converter_tools.py --firmware /path/to/firmware.zip

# Build GSI
python3 gsi_converter_tools.py --build-only /path/to/system.img

# Flash GSI
python3 gsi_converter_tools.py --flash-only /path/to/gsi.img

# Detect device info
python3 gsi_converter_tools.py --detect-device

# Install dependencies
python3 gsi_converter_tools.py --install-deps
