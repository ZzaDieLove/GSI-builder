## Third-Party Tools and Libraries

This project would not be possible without the following amazing open-source projects:

### Firmware Extraction Tools

#### payload-dumper-go
- **Author**: ssut
- **GitHub**: https://github.com/ssut/payload-dumper-go
- **License**: Apache License 2.0
- **Purpose**: Fast OTA payload extraction

#### sdat2img / img2sdat
- **Author**: xpirt
- **GitHub**: https://github.com/xpirt/sdat2img
- **License**: MIT License
- **Purpose**: Convert between sparse data and image formats

#### oppo_ozip_decrypt
- **Author**: bkerler
- **GitHub**: https://github.com/bkerler/oppo_ozip_decrypt
- **License**: MIT License
- **Purpose**: Decrypt Oppo/Realme OZIP firmware

### Android Tools

#### AOSP Build Tools
- **Source**: Android Open Source Project
- **License**: Apache License 2.0
- **Tools**: simg2img, img2simg, make_ext4fs, lpunpack, lpmake

#### Android SDK Platform Tools
- **Source**: Google
- **License**: Android SDK License
- **Tools**: adb, fastboot

### Python Libraries

#### protobuf
- **Source**: Google
- **License**: BSD 3-Clause
- **Purpose**: Protocol buffer support

#### pycryptodome
- **Source**: Legrandin
- **License**: BSD 2-Clause
- **Purpose**: Cryptographic operations

#### twrpdtgen
- **Author**: SebaUbuntu
- **GitHub**: https://github.com/sebaubuntu-python/twrpdtgen
- **License**: Apache License 2.0
- **Purpose**: TWRP device tree generator

#### extract-dtb
- **Author**: Pablo Mendez Hernandez
- **GitHub**: https://github.com/PabloMendezHernandez/extract-dtb
- **License**: MIT License
- **Purpose**: Extract DTB from kernel images

## How to Contribute

We welcome contributions! Here's how you can help:

### Code Contributions
1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Submit a pull request

### Documentation
- Fix typos and errors
- Add examples and clarifications
- Translate to other languages

### Testing
- Test on your device
- Report bugs with logs
- Verify fixes

### Community Support
- Help others in forums
- Share your experience
- Write guides for your device

### Feature Requests
- Suggest new features
- Report missing firmware support
- Request documentation improvements
